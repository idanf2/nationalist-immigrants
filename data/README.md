This folder should contain the following three data files, which are not included in this repository due to redistribution restrictions:
- `cmps_2016.rda`: Collaborative Multiracial Post-Election Survey 2016. Download from ICPSR study 38040: https://www.icpsr.umich.edu/web/ICPSR/studies/38040
- `cmps_2020.rda`: Collaborative Multiracial Post-Election Survey 2020. Download from ICPSR study 39096: https://www.icpsr.umich.edu/web/ICPSR/studies/39096
- `gss_1972_2024.sav`: General Social Survey cumulative file (1972–2024, Release 3). Download from NORC at the University of Chicago: https://gss.norc.org/get-the-data

After downloading, rename the files to match the names above and place them in this folder.
